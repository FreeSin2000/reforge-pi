# 图型模板集

> 复制骨架，替换内容。所有示例为纯 ASCII，宽度 < 80。中文只出现在图外。

## §1 阶段流水线（pipeline）

**用于**：顺序推进的调用链、启动流程、协议握手。最常用。

```
════════════════════════════════════════════════════════════
 stage N · <name>                      <file 或环境>
════════════════════════════════════════════════════════════
   <起点>
        │  <触发条件 / 传参>
        ▼
   file.c:123  symbol()
        ├─ sub_step_1()
        ├─ sub_step_2()
        └─ sub_step_3()
        │
        ▼
   next.s:45   next_symbol
════════════════════════════════════════════════════════════
```

要点：每阶段一个 `════` 带；阶段内用 `├─/└─` 列子步骤；箭头旁写条件或参数。

## §2 时序（sequence）

**用于**：多个执行体（进程/CPU/阶段）之间的先后交互。

```
  CPU0            CPU1            HW              time
   │               │               │                │
   │  step A       │               │                │
   │──────────────►│               │                │  t0
   │               │  program      │                │
   │               │──────────────►│                │  t1
   │               │               │  irq           │
   │               │◄──────────────│                │  t2
   │◄──────────────│               │                │  t3
   ▼               ▼               ▼                ▼
```

要点：列＝执行体；横线＝动作；`►` 方向＝调用/信号；行尾标时间或事件。

## §3 状态机（state）

**用于**：任务/进程/连接的状态迁移。

```
        fork()
   ┌──────────────┐
   ▼              │
 [NEW] ──wake─► [READY] ──schedule──► [RUNNING] ──exit──► [EXIT]
                   ▲                    │  ▲
                   │                    │  │
                   └──────sleep─────────┘  │
                                           │
                        preempt / yield ───┘
```

要点：方框＝状态；有向边＝事件；自环/双向用 `│ ▲` 绕回。

## §4 内存 / 地址空间布局（layout）

**用于**：地址空间、栈/堆、解压前后布局。

```
 high 0xffffffff ┌──────────────────────┐
                 │ kernel text/data/bss │  __START_KERNEL_map
                 ├──────────────────────┤
                 │ vmalloc / modules    │
                 ├──────────────────────┤
                 │ ------- hole ------- │
                 ├──────────────────────┤
                 │ user stack           │  grows down
                 │        ▼             │
                 │        ▲             │
                 │ user heap            │
 low  0x00000000 └──────────────────────┘
```

要点：纵轴标地址；`grows down/up` 标方向；每段右侧注释归属。

## §5 数据结构（struct / list / tree）

**用于**：链表、树、结构体字段。

```
 struct task_struct
 ┌─────────────────────────┐
 │ pid_t        pid        │
 │ volatile long state     │
 │ struct mm_struct *mm ───┼──► struct mm_struct
 │ struct list_head tasks ─┼──► [prev|next] <──► task A <──► ...
 └─────────────────────────┘
```

要点：字段右对齐；指针用 `───►` 指向目标结构；嵌入的 head 用 `[prev|next]`。

## §6 分层架构（layered）

**用于**：VFS / 网络协议栈 / 驱动模型。

```
   ┌───────────────────────────────────────┐
   │ app:  read() / write()                │  syscall ABI
   ├───────────────────────────────────────┤
   │ VFS:  file_operations                 │
   ├───────────────────────────────────────┤
   │ FS:   ext4 / xfs / btrfs              │
   ├───────────────────────────────────────┤
   │ block: bio / request                 │
   ├───────────────────────────────────────┤
   │ driver: nvme / virtio_blk            │
   └───────────────────────────────────────┘
```

要点：层间竖排；每层写其抽象接口名；跨层数据流另用箭头标。

## §7 数据流（dataflow）

**用于**：一个结构体/参数被层层传递和变换。

```
 bootloader
     │  fill
     ▼
 boot_params ──%esi──► startup_32 ──%rsi──► startup_64
                                              │ %r15
                                              ▼
                              x86_64_start_kernel(char *rmode)
                                              │ copy_bootdata()
                                              ▼
                                         global boot_params
```

要点：节点＝持有者；箭头＝传参（标寄存器/形参）；末端＝最终归宿。

## §8 决策 / 分支（decision）

**用于**：条件分歧、多入口选择。

```
                 <input>
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
  [cond A]     [cond B]     [else]
     │             │            │
   path_1        path_2       path_3
     │             │            │
     └─────────────┼────────────┘
                   ▼
                <merge>
```

要点：`┌┼┐` 分叉，`┼` 汇合；分支顶部写条件；避免超过 4 路（拆图）。
